# MindShift — Game Design

## Vision
A mobile intellectual puzzle game where the player learns to question assumptions, recognize patterns, and switch reasoning strategies.

## Core pillars
1. **Reasoning over guessing** — solutions must be logically defensible.
2. **Surprise** — some puzzles punish the most obvious interpretation.
3. **Progressive complexity** — introduce one concept, then combine concepts.
4. **Short sessions** — a puzzle should usually be solvable in 30 seconds to 3 minutes.
5. **Useful hints** — hints reveal a direction, not the complete answer.

## Puzzle categories
- Logic
- Pattern recognition
- Spatial reasoning
- Observation
- Memory
- Sequence reasoning
- Time/constraint puzzles
- Perspective / assumption-switch puzzles

## Difficulty
- 1–20: onboarding
- 21–50: intermediate
- 51–100: advanced
- 100+: expert MindShift challenges

## Player feedback
After selected levels, show a lightweight reasoning profile based on behavior:
- Logical
- Analytical
- Creative
- Observant
- Impulsive

This is a game feature, not a psychological diagnosis.

## MVP acceptance criteria
- A player can start a level, solve it, receive immediate feedback, and advance.
- Invalid answers do not advance progression.
- Hints are limited and do not reveal the full solution immediately.
- Progress survives app restart.
- Puzzle definitions are data-driven so new levels can be added without rewriting the engine.
