# MindShift Store Listing & Screenshot Capture Plan

This file is the release-candidate source of truth for storefront copy and the screenshot set. It contains proposed copy and capture criteria; it does not claim owner approval, publication, or real-device capture.

## Store listing copy

### Short description (draft)

Train your mind with bite-sized logic puzzles, hints, streaks, and daily challenges.

### Full description (draft)

MindShift is a focused puzzle game built around short, satisfying logic challenges.

Solve one puzzle at a time, learn from clear feedback, and build a consistent streak as you progress through increasingly difficult challenges.

**What you can do**
- Solve data-driven logic puzzles across multiple categories and difficulty levels.
- Use hints when you need a nudge without losing the flow of the game.
- Track completed levels and progression between sessions.
- Take on a Daily Challenge and keep your streak alive.
- Review results, achievements, and progress as you improve.
- Play through a mobile-first interface designed for quick sessions.

**Designed for focused play**
MindShift keeps the core loop simple: read, think, answer, learn, and move to the next challenge. Incorrect answers do not silently advance your progress.

**Release note**
This draft intentionally avoids claims about online services, ads, purchases, or telemetry. Those statements must be updated only after the final release configuration and privacy review are approved.

## Screenshot set

Capture four portrait screenshots from the release candidate on a real Android device when the device gate becomes available:

1. **Home** — clean landing screen with the primary play/navigation actions visible.
2. **Puzzle** — active puzzle with readable question, answer input, and hint affordance.
3. **Result** — completed puzzle result with success/failure feedback and next/retry flow visible.
4. **Daily Challenge** — daily challenge/streak state with no debug overlays.

### Capture acceptance checklist

- [ ] Captured from the release-candidate build, not an editor/debug preview.
- [ ] Portrait orientation and production UI only.
- [ ] No debug text, developer controls, test data, or placeholder artwork.
- [ ] Text remains readable at storefront display size.
- [ ] No clipping around display cutouts, safe areas, buttons, inputs, or panels.
- [ ] Each screenshot communicates one clear feature/state.
- [ ] Final storefront-required dimensions/export format verified against the current Google Play requirements before upload.
- [ ] Owner approval recorded before publication.
