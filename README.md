# MindShift 🧠

MindShift is a mobile-first intellectual puzzle game built around one idea: **don't just find the answer — change the way you think.**

## MVP
- 10 deterministic puzzles
- Puzzle engine and level manager
- Answer validation
- Hint system
- Progress/save system
- Player reasoning statistics
- Mobile-first UI
- Automated validation tests

## Development workflow
Notion is the product/project source of truth. GitHub is the code and engineering source of truth.

Idea → Notion task → GitHub issue → branch → implementation → PR → tests → merge → update project status.

## Project structure
- `docs/` — game design and technical documentation
- `data/` — puzzle definitions
- `src/` — implementation (to be added with the chosen runtime)
- `.github/` — CI and contribution automation
